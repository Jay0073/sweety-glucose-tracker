# Responsive QA evidence

These captures document the final browser pass at 1440×1000 and 390×844. The pass covered the time-aware reading form, same-day and historical backfill, the anchored mobile calendar and scroll lock, populated month-to-date reports, the export menu, and the Daily → Month-to-date → Daily transition that previously caused a blank screen.

The three submission-facing screenshots remain in `docs/screenshots/`; this folder keeps the additional states used during responsive verification.
